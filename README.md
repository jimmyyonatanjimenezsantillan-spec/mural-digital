# Mural Digital

Un mural interactivo para compartir fotografías y recuerdos en una cuadrícula visual con controles de zoom y desplazamiento.

## Uso

Abre `index.html` en un navegador moderno. No requiere instalación ni compilación. El catálogo de estados y municipios se incluye localmente en `municipios.js`.

## Participación

Elige un espacio vacío, completa tus datos y selecciona una imagen para enviar una solicitud de revisión. En esta versión, solicitudes, aprobaciones y rechazos se guardan únicamente en el almacenamiento local del navegador; no se comparten con otros visitantes ni se publican en un servidor.

Para ofrecer participación compartida se necesita integrar un backend para almacenar imágenes y solicitudes, administrar reservas y permitir moderación autenticada.

## Archivos

- `index.html`: estructura del mural y formularios.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: interacciones, selección de espacios y persistencia local.
- `municipios.js`: catálogo local de estados y municipios de México.
